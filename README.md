# 🤘 METAL ROAD ― 0からのバンド成功物語

メタルバンドの成功物語をテーマにした**ソロプレイ双六ボードゲーム**のプロトタイプです。
人生ゲームをベースに、ソロ専用・ランク制（＝最後に立てるライブ会場の規模）へ作り替えています。

弱小バンドを率いて路上から這い上がり、サイコロを振ってライブやイベントを乗り越え、
**ファン数・演奏スキル・メンバー士気・資金**を育てながら、集大成ライブで立てる会場の規模＝ランクを目指します。

## 遊び方

1. サイコロ（1〜3）を振ってコマを進める
2. 止まったマスのイベントが発生。選択肢があるものは選んで展開が変わる
3. 分岐点ではルートを選ぶ（実力派 / バズ狙い、インディーズ継続 / メジャー契約）
4. ゴール（集大成ライブ）に到達すると、その時のステータスから**会場＝ランク**が確定
5. いずれかのパラメータが尽きる / 期限超過で**特殊エンディング**（ゲームオーバー）

### ランク（＝ライブ会場の規模）の決まり方

- **ファン数** … 到達できる会場の「上限キャパ」を決める
- **演奏スキル × メンバー士気** … 会場を成立させられるかの品質係数。低いと格下げ
- **資金** … 大箱（アリーナ以上）の確保ゲート。不足だと格下げ

`E:路上 → D:小箱 → C:ホール → B:Zepp → A:アリーナ → S:武道館 → SS:東京ドーム`

### 特殊エンディング

| 条件 | エンディング |
| --- | --- |
| ファン数 0 | 誰も来ない解散ライブ |
| 演奏スキル 0 | イップス（演奏不能） |
| メンバー士気 0 | 音楽性の違い・不仲解散 |
| 資金が借金限度超え | 夜逃げ（高利貸しに追われて） |
| 期限内にゴール未達 | 実家へ（家業を継ぐ） |

## 開発

```bash
npm install
npm run dev      # 開発サーバ (http://localhost:5173)
npm run build    # 型チェック + 本番ビルド
npm run preview  # ビルド成果物のプレビュー
```

### 技術スタック

- React 18 + TypeScript + Vite
- Framer Motion（アニメーション）
- SVG 自作グラフィック（盤面・コマ）
- 効果音は Web Audio API で合成（音源ファイル不要）

### 構成

```
src/
  types.ts              ドメインモデル（Stats / Square / GameEvent / Ending …）
  data/
    board.ts            盤面（分岐つき）と座標
    events.ts           イベント定義
    venues.ts           会場ラダーとランク算出ロジック
    endings.ts          特殊/成功エンディング
  game/
    engine.ts           初期状態・効果適用・ゲームオーバー判定・ゴール処理・CONFIG
    reducer.ts          ゲーム進行のステートマシン（移動/分岐/イベント/ターン）
  hooks/useGame.ts      reducer 駆動 + 移動アニメ + 効果音
  audio/sfx.ts          Web Audio による効果音合成
  components/           Board / StatusPanel / EventModal / BranchModal / Ending …
scripts/sim.ts          バランス検証用ヘッドレスシミュレータ（任意）
```

### バランス調整のツボ

数値は集約してあります：

- `src/game/engine.ts` の `CONFIG`（サイコロ上限・期限ターン・借金限度・毎ターン活動費 など）
- `src/data/venues.ts` の `VENUES`（各ランクの必要ファン数）と品質係数の閾値
- `src/data/events.ts` の各イベントの効果値

ヘッドレス検証（200回プレイのランク分布を確認）:

```bash
npx esbuild scripts/sim.ts --bundle --platform=node --format=esm --outfile=/tmp/sim.mjs && node /tmp/sim.mjs
WORST=1 node /tmp/sim.mjs   # 最悪選択でのプレイ
```
